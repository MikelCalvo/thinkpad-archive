# Sources, attribution and publication boundary

The catalogue contains factual model/package identifiers, concise metadata, source links and optional fingerprints. A citation records where an identity or listing was observed. It does not prove that a current download is available, that a publisher's claims have been tested on hardware or that redistribution is permitted.

## Evidence levels

A manufacturer listing records advertised package information on a model-specific source route. These pages can contain shared packages for other systems; they are not exact-variant installation instructions. A package's own model list is stronger evidence for an explicit model association but still does not prove a working installation. Neither level establishes hardware-tested compatibility.

Source digests establish only the observed bytes, not publisher signatures, legal rights or future availability. A source digest need not be the hash of an installer. Catalogue record counts must not be presented as counts of distinct, verified executable downloads.

## Excluded from this repository and its history

- IBM/Lenovo PDFs, installers, original README bodies and captured website files.
- Third-party logos or assets without a verified license.
- Personal inventories, physical-media records, drive serials, absolute local host paths or operational logs.
- Private credentials, archives of manufacturer originals and generated outputs containing them.

HTTPS availability is not a redistribution license. The public site links to sources instead of mirroring proprietary documents or executable packages. No package is automatically downloaded or run during a build or page visit.

## Source limits

Grouped manufacturer entries retain their identity or list only source-supported aliases. Release years, CPU specifications, exact OS support and package completeness must not be guessed from names. A fixed catalogue version is a snapshot, not a monitoring service. Report external-link availability only where it was actually checked, and do not confuse a source listing with a verified package download.
