# Historical year backfill, 0.3.2

The 0.3.2 pass reviewed all eight previously unresolved catalogue entries or groups. It adds seven exact variant years across five records. The catalogue still contains 666 model entries; 665 now have at least one documented year. These counts include explicitly qualified commercial-listing and regional-availability evidence, not only confirmed first launches.

## Accepted evidence

| Catalogue entry | Year added | What the source actually establishes |
| --- | --- | --- |
| R52 types 1850 and 1870 | 2005 | Both exact types appear in the specification headings of IBM commercial brochure TPD00885-USEN-00, page 3, dated March 2005. The public copy is a third-party mirror. This is a dated commercial listing, not a proved announcement or first sale.[1] |
| R52 types 1862 and 1863 | 2005 | Both exact types appear in the other specification-column heading of that same dated brochure. The year is not inherited from ordinary R52 types.[1] |
| Edge E31, Chinese SKU 025027C | 2011 | Sina explicitly labels February 2011 as this exact configuration's market-introduction month. This is a regional SKU date, not the first worldwide E31 launch.[2] |
| X200si, Dutch SKU NS2FVMH | 2010 | Tweakers explicitly records availability since 28 April 2010 in the specifications detail. This is the price-comparison service's regional availability record, not an independently proved global launch.[3] |
| X230i Tablet, German campus SKU 3438-AK8 | 2012 | A dealer forecasts delivery for 9 July 2012; an owner documents receipt and the exact X230i Tablet commercial name on 29 July 2012. Together they establish 2012 regional availability, not a precise worldwide first-launch day.[4][5] |

Each accepted row carries a machine-readable evidence kind and an English/Spanish scope note. Model pages use “Documented years” instead of “Introduced in” for qualified records and show the caveat beside the citation. The timeline uses the cited year as navigation metadata; it does not claim that every listed year is the first worldwide launch.

## Conflicts and rejected shortcuts

Lenovo already names Edge E31 machine types 0217/0250 in a September 2010 driver document. Its date is not used as a laptop launch date, but it prevents presenting the February 2011 Chinese configuration as the first E31 worldwide.[6]

The X230i Tablet owner explicitly flags an erroneous Lenovo lookup for 3438-AK8. Current support normalizes that SKU to X230 Tablet. The accepted claim is restricted to the contemporary commercial i-name and exact regional SKU; it does not relabel all type 3438 machines.[5]

The R52 brochure's printed warranty table describes one- or three-year warranties, while IBM's current export registry describes the four special-bid types as four-year warranty configurations. The exact type headings are still explicit; the brochure is not represented as a four-year-warranty availability announcement.[1]

The search did not find adequate corroboration for the retrospective 2009 X200si launch assertion on an undated repair website. It also did not establish a first-worldwide launch for the accepted 2010 Dutch SKU. Neither uncertainty is hidden by the new date.

Research used manufacturer documents, contemporary German dealer/owner material, Chinese product-introduction fields and a Dutch exact-SKU availability record. A blocked search route is a retrieval limit, not evidence that a product did not exist. Captured pages, PDFs, full source text and browser state stay outside the public repository; only factual metadata, source links and original review notes are published.

Existing document and driver metadata, support routes and every model's driver/document associations are unchanged. No compatibility is inferred from the newly dated variants.
